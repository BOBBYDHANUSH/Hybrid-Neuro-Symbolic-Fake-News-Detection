## 📌 Overview

This project presents a **Hybrid Neuro-Symbolic Fake News Detection System** that combines traditional Machine Learning, Deep Learning, and Explainable AI techniques to improve fake news detection accuracy and transparency.

The system integrates:

- TF-IDF + Logistic Regression
- BERT Transformer
- Semantic Verification
- Temporal Verification
- Spatial Verification
- Explainable Rationale Generation

Unlike conventional fake news classifiers, this project not only predicts whether news is **Real** or **Fake** but also provides human-readable explanations and verifies supporting metadata.

---

## 🎯 Objectives

- Detect fake news using multiple AI techniques.
- Improve prediction accuracy through hybrid learning.
- Provide explainable predictions.
- Verify semantic consistency.
- Validate temporal and spatial metadata.
- Compare traditional ML with transformer-based models.
